## 📌 О проекте

**Mosquito Zone AI** — это гибридная система видеонаблюдения, построенная на базе:

- 🎥 **ESP32-CAM** — компактные камеры для видеозахвата
- 🧠 **ZoneMinder** — мощный видеосервер для хранения и обработки
- 👤 **Face Recognition** — идентификация лиц в реальном времени
- 📡 **MQTT (Mosquitto)** — управление поворотными механизмами камер
- 🤖 **AI-детекция** — распознавание объектов и лиц

Система автоматически поворачивает камеры, отслеживая обнаруженные лица, и уведомляет оператора через MQTT.

### 🎯 Основная идея
Проект спроектирован так, чтобы простая и недорогая камера ESP32-CAM работала на уровне дорогостоящих промышленных решений.

**Ключевое преимущество** — передача данных по **Wi-Fi**, что позволяет размещать камеру где угодно. Питание может быть организовано различными способами:
- 🔌 По проводу от сети 220В
- 🔋 От аккумулятора
- ☀️ От солнечных панелей

### ⚙️ Как это работает

1. **ESP32-CAM** запускает веб-сервер и транслирует видеопоток.
2. Встроенный веб-интерфейс позволяет управлять **двумя сервоприводами** (поворот и наклон).
3. Трансляция захватывается **ZoneMinder** на одноплатном ПК (Orange Pi ZERO 3), где происходит:
   - Обработка видеопотока
   - Хранение архива
   - Интеграция с модулем распознавания лиц (разработан в рамках дипломной работы)

### 🧠 Распознавание лиц
- Используется **обученная модель**, занесенная в базу данных.
- Система идентифицирует лица и выводит статус: **"Разрешен вход"** или **"Посторонний"**.
- При обнаружении постороннего — отправляется уведомление, сохраняется **кадр с обведенным лицом** в историю событий.

> **Важно:** чтобы не перегружать ESP32-CAM (при высокой нагрузке плата перегревается и уходит в перезагрузку), все вычисления вынесены на **Orange Pi ZERO 3**, а ESP32 выполняет только трансляцию видео и управление сервоприводами.

## 🚀 Быстрый старт

### Минимальная конфигурация
- **ESP32-CAM** — 1 шт.
- **Одноплатный ПК** с Linux (Orange Pi, Raspberry Pi) для установки ZoneMinder

### Шаги по установке

#### 1. Настройка ESP32-CAM
- Загрузите скетч из примеров Arduino (или используйте готовый код из моего репозитория)
- Настройте подключение к Wi-Fi сети
- Получите IP-адрес камеры и проверьте веб-интерфейс

#### 2. Настройка сервера
- Установите **ZoneMinder** на Linux-сервер
- Настройте захват видеопотока с ESP32-CAM
- Настройте **MQTT Broker (Mosquitto)** для управления сервоприводами
- Интегрируйте модуль распознавания лиц (поставляется отдельно)

> 📖 **Полная инструкция** по установке и настройке доступна в [документации](docs/setup-guide.md).

## ❓ Часто задаваемые вопросы (FAQ)

**Q: Можно ли использовать проект без сервера?**  
A: Да, ESP32-CAM может сохранять снимки на SD-карту, но для полноценного распознавания лиц и видеосервера требуется сервер.

**Q: Сколько камер можно подключить?**  
A: Теоретически неограниченно, ограничение — производительность вашего сервера.

**Q: Могу ли я получить отдельно код для ESP32-CAM?**  
A: Да, запросите через контакты, я предоставлю отдельный скетч.

**Q: Почему распознавание лиц выполняется не на ESP32?**  
A: ESP32-CAM перегревается при высокой нагрузке и уходит в перезагрузку, поэтому все вычисления вынесены на Orange Pi.
