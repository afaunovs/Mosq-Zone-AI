## 🔄 Поток данных

### 1. Видеопоток (ESP32 → ZoneMinder)
ESP32-CAM → HTTP/RTSP → ZoneMinder → Сохранение в архив

text

- ESP32-CAM транслирует видео через встроенный веб-сервер (HTTP)
- ZoneMinder захватывает поток по протоколу RTSP/HTTP
- Видео сохраняется на сервер с интервалом 10 минут (файлы .mp4)

### 2. Команды управления (MQTT)
ZoneMinder/ИИ → Mosquitto (MQTT) → ESP32-CAM → Сервоприводы

text

- Топики:
  - `mosq-zone/camera/pan` — поворот (LEFT/RIGHT)
  - `mosq-zone/camera/tilt` — наклон (UP/DOWN)
  - `mosq-zone/face/detected` — событие обнаружения лица
  - `mosq-zone/system/status` — статус системы

### 3. Распознавание лиц
ZoneMinder (кадр) → Face Recognition (Python) → Результат → MQTT

text

- Каждый N-й кадр отправляется в модуль распознавания
- Модуль сравнивает лицо с базой данных (собственная обученная модель)
- Ответ: `KNOWN` (свой) или `UNKNOWN` (чужой)
- При `UNKNOWN` отправляется уведомление и сохраняется кадр с обведенным лицом

## 🧠 Принципы проектирования

### Почему обработка не на ESP32?

| Проблема | Решение |
|----------|---------|
| ESP32-CAM перегревается при высокой нагрузке | Все вычисления вынесены на сервер |
| Ограниченная память (4MB Flash) | Модель распознавания хранится на сервере |
| Сложность обновления модели | Обновление на сервере без перепрошивки камеры |
| Энергопотребление | ESP32 только транслирует видео и управляет сервоприводами |

### Масштабируемость
- Можно добавить до 10+ камер на один сервер (ограничение по CPU Orange Pi)
- Каждая камера регистрируется в ZoneMinder автоматически
- MQTT позволяет управлять всеми камерами централизованно

---

## 🔐 Безопасность

- Wi-Fi сеть с WPA2-PSK
- MQTT с паролем (в production)
- Закрытый порт для веб-интерфейса (не публичный)
- HTTPS планируется в будущем
