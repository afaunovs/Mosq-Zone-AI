# 🖥️ Спецификация оборудования Mosq-Zone AI

## Основные компоненты

| Компонент | Модель | Назначение |
|-----------|--------|------------|
| **ESP32-CAM** | AI Thinker | Основной модуль камеры |
| **ИК-подсветка** | Yumiki 4006-F | Ночная съемка |
| **Понижающий модуль** | TZT MP1584EN 3A | Стабилизация питания 5В |
| **Фильтр день/ночь** | Двойной SD&HI | Переключение режимов |
| **Объектив** | ESCAM | Качество изображения |
| **Блок питания** | AC-DC 12В 1.5А / 5В 2А | Основное питание |
| **Модуль двигателя** | MX1508 | Управление сервоприводами |
| **Выносная антенна** | 2.4GHz SMA | Улучшение Wi-Fi |

## Серверная часть

| Компонент | Модель | Характеристики |
|-----------|--------|----------------|
| **Одноплатный ПК** | Orange Pi ZERO 3 | 4-ядерный ARM Cortex-A55, 2GB RAM |
| **Операционная система** | Armbian / Debian12 | Linux |
| **Накопитель** | MicroSD 32GB / ssd 128GB+  | Для системы и архива |
| **Переходник с разъема ssd на usb 3.0** | Для подключения |

## Рекомендации по выбору

### ESP32-CAM
- ✅ Выбирайте модуль AI Thinker (оригинал)
- ❌ Избегайте дешевых клонов (нестабильная работа)

### Питание
- ✅ Требуется стабильное 5В 2А (минимум)
- ❌ USB от компьютера — НЕ ПОДХОДИТ (недостаточно тока)

### Сервоприводы
- Рекомендуются сервоприводы с металлическим редуктором
- Угол поворота: 180° (стандартные) или 360° (модифицированные)

### Сервер
- Orange Pi ZERO 3 достаточно для 2-3 камер
- Для >5 камер рекомендуется Raspberry Pi 4 или x86 ПК
